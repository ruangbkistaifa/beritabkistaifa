# Berita Prodi BKI STAIFA Pamekasan

Situs berita Program Studi Bimbingan dan Konseling Islam STAI Al Falah (STAIFA) Pamekasan, dibangun dengan Jekyll dan GitHub Pages.

- Cara menulis dan menerbitkan berita: lihat **PANDUAN-MENULIS.md**
- Templat berita baru: **TEMPLATE-BERITA.md**
- Pengaturan situs (nama, alamat, kontak, tautan layanan): **_config.yml**
- Daftar rubrik: **_data/rubrik.yml**
